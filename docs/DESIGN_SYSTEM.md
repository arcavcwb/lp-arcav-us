# Sistema de diseño (obsoleto)

Este documento está archivado. **No lo uses como referencia de diseño.**

El sistema visual vigente está en `DESIGN.md`, en la raíz del repositorio:
paleta, tipografía Barlow y Barlow Condensed, layout, componentes y reglas
nombradas. Los tokens implementados viven en el `:root` de
`src/styles/global.css`.

La paleta y los tokens que contenía este archivo (entorno azul marino con
acento coral) no corresponden al sitio publicado y se eliminaron para que
ninguna lectura parcial los reintroduzca.
