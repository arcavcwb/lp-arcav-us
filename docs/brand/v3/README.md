# Kit de identidad ARCAV V3 (referencia)

Copia de referencia del kit entregado el 21/11/2026: la guía (`BRAND_KIT_V3.md`) y los 11 logos y símbolos en SVG (`logos-svg/`). Los SVG no tienen scripts ni recursos externos.

El sitio no lee estos archivos:

- El logo del sitio es `src/components/ui/Logo.astro`, el mismo dibujo en línea con los colores de los tokens.
- Los colores y las fuentes viven en `src/styles/tokens.css`. El CSS y el JSON de tokens del kit no se copiaron para no tener dos fuentes de verdad.
- El favicon y el ícono de Apple están en `public/`, generados a partir de `logos-svg/favicon.svg` en formato cuadrado.

El PDF y los PNG de vista previa del kit quedan fuera del repositorio.
