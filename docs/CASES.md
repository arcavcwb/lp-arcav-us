# ARCAV — Case Study Rules

## General

Cases must demonstrate how Armando thinks and works.

Do not reduce them to screenshots and technology lists.

Preferred structure:

1. Context
2. Problem
3. Existing process
4. Constraints
5. Decision
6. Solution
7. Architecture / flow
8. Outcome or learning
9. Technologies as supporting evidence

Do not invent measurable outcomes.

---

## Case 01 — End-to-end product

Working title:

**De operación manual a producto digital operativo**

Source context:

Independent product work, including restaurant/order/kitchen/delivery operations.

What it demonstrates:

- User-flow thinking
- Product definition
- Frontend
- Backend
- Database
- Business rules
- Deployment
- Infrastructure
- Maintenance
- End-to-end ownership

Core message:

**Construir una interfaz es diferente a hacerse responsable de que el producto completo funcione.**

## Case 02 — Automation and integration

Working title:

**Integrar sin invadir**

What it demonstrates:

- Process understanding
- API integration
- n8n orchestration
- Data transformation
- De-duplication / sanitation where applicable
- Independent integration layer
- Reduced coupling
- Respect for existing systems

Useful anonymized example:

A campaign captured leads while another internal system managed the operational source of truth.

The solution connected authorized data through an independent layer instead of directly modifying interconnected internal systems.

Core message:

**No todo problema necesita una migración.**

Confidentiality:

Do not expose current client/company internal systems, screenshots, proprietary architecture, product names, or protected information.

## Case 03 — arcav-ia-flow

Working title:

**Diseñar el sistema que construye el sistema**

Public project:

https://github.com/arcavcwb/arcav-ia-flow

What it demonstrates:

- Product methodology
- Agentic workflow design
- Separation of responsibilities
- Architecture
- QA
- Independent review
- DevOps
- Governance
- AI-assisted product delivery

Core message:

**No utilizo IA únicamente para programar más rápido. La utilizo para mejorar todo el proceso de construcción de producto.**

Do not lead with the number of agents as the value proposition.

The value is the system and the product-building method.
