# Arquivos de marca da ARCAV

Coloque aqui os arquivos oficiais. O site os usa automaticamente no próximo build;
enquanto não existirem, mostra o wordmark de texto.
As fotos (retratos e outras) ficam em `src/assets/fotos/`; veja o README de lá.

| Arquivo | Onde aparece | Formato recomendado |
|---|---|---|
| `arcav-logo.svg` (ou `.png` / `.webp`) | Cabeçalho e rodapé, no lugar do wordmark "ARCAV" | SVG em uma cor escura (#1C1D21), fundo transparente, altura visual de ~28 px |

O favicon (`public/favicon.svg`) é um monograma provisório; troque-o quando o símbolo oficial estiver pronto.
